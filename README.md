-------------- Online Library Application -----------------

Jednostavna Spring Boot web aplikacija za upravljanje bibliotekom, pisana u Javi uz korištenje Thymeleaf šablona i CSS-a za stilizovanje sučelja.

Tehnologije:
* Java 25
* Spring Boot
* Thymeleaf (HTML template)
* CSS
* Maven

Struktura projekta:

onlineLibrary/
├── src/
│   └── main/
│       ├── java/com/example/onlinelibrary/
│       │   ├── controller/      
│       │   ├── data/            
│       │   ├── model/          
│       │   └── service/
│       └── resources/
│           ├── static/style/    
│           └── templates/      
└── pom.xml
